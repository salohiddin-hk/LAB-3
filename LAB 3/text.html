The <p> Tag

Definition: The paragraph tag defines a block of text as a distinct paragraph.

Attributes

Attribute Role
class / id Applies CSS styles or unique identifiers to the paragraph.

Example (Code)

<p>This is a sample paragraph demonstrating text formatting.</p>
